# Countdown Telegram Bot

Telegram-бот для обратного отсчёта до заданной даты и времени в групповом чате.

## Команды

- `/start` — инструкция
- `/countdown Название события | 2026-12-15 12:00` — создать отсчёт
- `/list` — показать активные отсчёты в текущем чате
- `/stop 1` — остановить отсчёт по ID
- `/help` — помощь

Дата и время задаются в часовом поясе `Europe/Moscow` (МСК) по умолчанию.
Бот обновляет своё сообщение раз в минуту. Управлять отсчётами могут администраторы группы.

## Запуск на Railway

1. Создай Telegram-бота через @BotFather и скопируй токен.
2. Подключи этот GitHub-репозиторий к Railway.
3. Добавь переменную окружения `BOT_TOKEN`.
4. (Рекомендуется) Подключи Railway Volume и укажи `DATABASE_PATH=/data/countdowns.db`, чтобы база сохранялась при пересоздании контейнера.
5. Запусти сервис командой `python main.py` (она уже указана в railway.json).

Дополнительные переменные:
- `TIMEZONE` — часовой пояс, по умолчанию `Europe/Moscow`.
- `DATABASE_PATH` — путь к SQLite базе, по умолчанию `countdowns.db`.

Боту не нужны права администратора Telegram-группы для редактирования собственных сообщений. Он должен оставаться участником чата.
